class ProbabilisticStatistics(model_id: str, client: Client)#

Bases: object

Per-model probabilistic analysis variable definitions (Monte Carlo / Latin hypercube).

Use sub-objects such as Material, Support, and Load to read and write statistics for each entity type. Values are generated protobuf messages (for example ProbabilisticVariable, MaterialProbabilisticVariable), not client-side dataclasses.

Material/Support/Hydraulic lists support addVariable/removeVariable/ setVariable/getVariable, and per-index field accessors such as getMean/setMean, getStdDev/setStdDev, getMin/setMin. Bulk list and composite get/set entry points are private (_getVariables, _setVariables, _getStatistics, _setStatistics).
