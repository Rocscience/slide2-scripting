AdvancedProjectSettings#

Advanced project settings (Advanced tab): tension, convergence, lambda, FS iteration, slice constraints, etc.

class AdvancedProjectSettings(model_id: str, client: Client)#

Bases: object

Examples: Code Snippet: Advanced Example
