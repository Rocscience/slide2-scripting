UserDefinedFunctions#

User-defined strength functions (Shear/Normal, C/Phi, Discrete, Undrained/Vertical stress). These are project-level function definitions; materials of the corresponding strength type select one by index via StrengthProperties.setStrengthType and setFunctionSelectionIndex.
