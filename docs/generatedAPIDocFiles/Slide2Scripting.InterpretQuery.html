class InterpretQuery(model_id: str, client: Client)#

Bases: object

Examples: Code Snippet: Interpret Query

Interpret Query menu: point-based slip surface query, graph series, and slice data.

getQueryData(point: Point2D, queryContext: QueryContext | None = None) → QueryData#

Returns query data for the slip surface at the point. Uses an existing query when one is already at that location; otherwise resolves the closest surface that Add Query would pick. query_index is -1 when the surface was resolved implicitly (not a saved query).

getQueryGraphData(point: Point2D, options: QueryGraphOptions, queryContext: QueryContext | None = None) → list[QueryGraphSeries]#
getGlobalMinSliceCount(queryContext: QueryContext | None = None) → int#

Returns the number of slices on the global minimum slip surface for the active analysis method.

getSliceData(slice_number: int, queryContext: QueryContext | None = None) → SliceData#

Returns slice data for one slice on the global minimum slip surface. slice_number is 1-based. Respects the current slice data filter settings in Interpret.

getAllSliceData(queryContext: QueryContext | None = None) → list[SliceData]#

Fetches slice data one slice at a time and returns the combined result. Use this for export/clipboard when the full dataset would exceed gRPC message limits.
