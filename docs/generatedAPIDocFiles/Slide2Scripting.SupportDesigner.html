Examples: Code Snippet: Support Designer

Support Designer scripting API: compute with wizard-equivalent inputs/validation, then apply results when a .s01sd file is available.

compute(settings: SupportDesignComputeSettings) → None#

Validate Support Designer inputs and start support-design compute (aslidew -supportdesign), matching the wizard compute path.

applyResults() → str#

Apply existing Support Designer results (.s01sd) to the model. Raises if no results file is available.
