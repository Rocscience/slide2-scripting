class DesignStandardsProjectSettings(model_id: str, client: Client)#

Bases: object

Examples: Code Snippet: Design Standards Example

Design Standards tab: selected design standard index, list of design standards, and set/add/delete user-defined design standards.

getSelectionIndex() → int#

Get the index of the currently selected design standard.

setSelectionIndex(selection_index: int)#

Set the selected design standard by index (0-based).

getDesignStandards() → List[DesignStandardEntry]#

Get list of design standards. Returns list of DesignStandardEntry objects.

setUserDefinedDesignStandard(selection_index: int, design_standard_setting: DesignStandardEntry)#

Update a user-defined design standard at the given index. design_standard_setting: DesignStandardEntry or dict with name, type, and factor fields.

addUserDefinedDesignStandard(design_standard_setting: DesignStandardEntry) → int#

Add a new user-defined design standard. design_standard_setting must have type set to a user-defined DesignStandardType (e.g. USER_DEFINED_EUROCODE). Accepts DesignStandardEntry or dict. Returns the new index.

deleteUserDefinedDesignStandard(selection_index: int)#

Delete the user-defined design standard at the given index.
